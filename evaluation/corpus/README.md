# Local evaluation corpus

This directory is reserved for public, vendor-issued molecular oncology sample reports used for local testing and demonstration.

The intended evaluation corpus contains 14 PDF reports. The archive supplied for this initial repository setup contains 12 PDFs; those 12 files have been unpacked locally without modification. The archive also contains a `download_failures.csv`, which is not part of the PDF corpus and has not been added here.

The report PDFs are deliberately excluded from Git and are not redistributed through this repository. Place authorized local copies in this directory using the filenames listed in `../corpus_manifest.csv`.
